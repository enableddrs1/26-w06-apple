# 🍎 사과 숫자 게임

시작 버튼을 눌러 게임을 시작한 뒤, 사과를 드래그해 합을 10의 배수로 만들고 점수를 얻는 1분 게임입니다.

## 게임 소개

시작 버튼을 누르면 8×8 보드에 숫자가 표시된 사과가 채워집니다. 사과를 가로 또는 세로로 이어 선택하고, 합이 10, 20, 30처럼 10의 배수가 되면 손을 떼어 수확하세요. 수확한 칸의 위쪽 사과가 아래로 내려오고, 맨 위 빈칸은 새 사과로 채워집니다. 제한 시간 60초 동안 더 높은 점수에 도전하며, 최고 점수를 새로 기록하면 컨페티 효과가 나타납니다.

## 어떻게 만들었나요

Copilot Agent에 게임 규칙과 화면 구성을 한 번에 설명해 Vanilla JS, HTML, CSS 파일로 나누어 구현했습니다. 포인터 입력으로 마우스와 터치 드래그를 처리하고, 브라우저의 `localStorage`에 최고 점수를 저장합니다.

## 실행 방법

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 별도의 설치나 빌드 과정은 필요하지 않습니다.

## 커스터마이징한 부분

- 합이 정확히 10일 때만 획득하는 규칙을 10의 배수 합계로 확장했습니다.
- 제한 시간을 1분으로 설정하고 최고 점수를 저장하도록 했습니다.
- 모바일에서도 드래그할 수 있도록 터치 입력과 반응형 레이아웃을 적용했습니다.
- 시작 버튼을 눌러야 게임이 시작되며, 사과를 수확하면 위쪽 사과가 내려와 보드를 채웁니다.
- 최고 점수 갱신 시 컨페티 효과를 보여주고, 모션 줄이기 설정도 존중합니다.

자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.
