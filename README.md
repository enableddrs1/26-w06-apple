# 🍎 사과 숫자 게임

사과를 이어 합계를 10의 배수로 만들고 수확하는 1분 퍼즐 게임입니다. 더 많은 사과를 수확해 최고 점수에 도전해 보세요!

## 게임 방법

1. **게임 시작** 버튼을 눌러 라운드를 시작합니다. 시작 전에는 보드가 비어 있습니다.
2. 보드에서 가로 또는 세로로 이웃한 사과를 드래그해 선택합니다.
3. 선택한 숫자의 합이 10, 20, 30처럼 **10의 배수**가 되면 드래그를 끝내 수확합니다.
4. 선택한 숫자의 합만큼 점수를 얻습니다. 수확한 칸 위쪽의 사과는 아래로 내려오고, 비어 있는 맨 위 칸에는 새 사과가 생깁니다.
5. 제한 시간 60초가 끝나기 전에 높은 점수를 기록하세요. 최고 점수는 브라우저에 저장됩니다.

합이 10의 배수가 아닌 상태로 드래그를 끝내면 점수를 얻지 못합니다. 게임이 끝난 뒤 **다시 하기**를 누르면 새 라운드를 시작할 수 있습니다.

## 게임 특징

- 숫자 1~9가 표시된 사과로 구성된 8×8 보드
- 마우스와 터치 드래그를 지원하는 인접 칸 선택
- 수확한 칸 위의 사과가 내려오는 열 단위 채우기
- 현재 점수, 남은 시간, 브라우저에 저장되는 최고 점수 표시
- 최고 점수를 새로 기록하면 나타나는 컨페티 효과
- 기기의 모션 줄이기 설정 지원
- 작은 화면에서도 사용할 수 있는 반응형 레이아웃

## 실행 방법

저장소를 내려받은 다음 `index.html`을 브라우저에서 여세요. 별도의 설치나 빌드 과정은 필요하지 않습니다.

## 구현

별도의 프레임워크 없이 HTML, CSS, Vanilla JavaScript로 만들었습니다. 포인터 이벤트로 마우스와 터치 입력을 처리하며, 최고 점수는 브라우저의 `localStorage`에 기록합니다.

- `index.html`: 게임 화면과 접근성 레이블
- `style.css`: 게임 보드, 반응형 스타일, 컨페티 애니메이션
- `script.js`: 타이머, 사과 선택과 수확, 점수 및 기록 관리

자세한 실습 절차와 커스터마이징 예시는 [guide.md](./guide.md)를 참고하세요.
